# 🌋 Balmatt Geothermal Project: Seismic Event Prediction

## 📌 Project Overview
This project develops a machine learning framework to predict induced seismicity at the **Balmatt Geothermal Power Plant** (operated by VITO, Mol, Belgium). 

Using high-frequency operational data (Flow, Pressure, Temperature) from **2019–2025**, this solution aims to:
1.  **Analyze** correlations between operational changes and seismic activity.
2.  **Predict** the probability of a seismic event ($M_L \ge 0.5$) in the next 7 days.
3.  **Forecast** the maximum expected magnitude ($M_{max}$) if an event occurs.
4.  **Monitor** these risks via an interactive Dashboard.
